# 翻译（translate）

基于子句分析，按工作目录设定的档位（briefing 的 `approach`，见 [literalness.md](literalness.md)）产出中文译文，并给出实词的译法对照，通过 `submit_translation` 提交。下面的示例和“span”“叙事文”两节按默认的第 2 档（直译）写；其他档位与之不同的地方，以 literalness.md 为准。

## 流程

1. 调 `build_translation_briefing(range)` 一次。还没有子句分析的节会报错，先做 analyze。范围超过约 10 节时按自然段分批：每批取一次 briefing、提交一次。批次边界放在段首：子句带 `paragraph` 时按它；没有时，如果有能对比各英文译本分段的扩展工具，分批前先取一次全范围的分段对比，放在多数译本和原文共同认可的段首。
2. 读 `approach`（档位）、`clauses`（带 `logic` 的是子句分析标出的逻辑关系，选连词“因为”“于是”“就”等时参照它）、`tokens`、`terms`（每个实词义项的术语表条目与既有译法）、`precedingTranslations`（前文）。
3. 逐子句翻译，组成 `translations` 数组。
4. 提交前把每节译文连起来通读一遍（逐词填的译法单看都对，连起来常出病句），检查：
   - 搭配：动宾、主谓、修饰语与中心语搭不搭配。形容词或名词带属格补语（`πλήρης`、`ἄξιος`、`μεστός`，希伯来文 `מָלֵא` 等）时，“满有 X”“配得 X”这类字面说法后面接不上，或成分一多就读不通，要改结构，如徒 9:36 `πλήρης ἔργων ἀγαθῶν καὶ ἐλεημοσυνῶν` 译“善事和施舍非常多”，字面说法放进 alternatives。
   - 修饰范围：定语、状语管到的词与原文一致，不会被读成只管一部分（见下文“关系从句”的并列先行词）。
   - 读得通：中文读不通的直译要改，档位允许的范围内调整语序、结构。
   - 原文的重复照译，不要当作冗余删并，可能本来就是强调。
5. 提交。若返回 `errors` 或 `consistency`，按提示修正后**整节**重提；已写入的节不要重提。
6. 本段新确定的专名、术语，用 `upsert_glossary` 写入术语表。

## 每个子句一项

```json
{
  "clauseId": "1001001a",
  "span": 1,
  "text": "起初神创造了诸天与大地",
  "renderings": [
    {"tokens": "o010010010012", "zh": "起初"},
    {"tokens": "o010010010021", "zh": "创造"},
    {"tokens": "o010010010031", "zh": "神"},
    {"tokens": "o010010010052", "zh": "诸天"},
    {"tokens": "o010010010072", "zh": "大地"}
  ],
  "paraTitle": "神创造天地"
}
```

- `text`：译文。第 1–3 档中补出的词用 `[ ]` 标出（范围按档位，见 literalness.md），第 4、5 档不用 `[ ]`；NA28/UBS 双括号内的经文，各档译文首尾都加 `〚 〛`。
- `supplied`：可选，补词的说明，每条 `{text, note}`，`text` 是某个 `[ ]` 里的文字（同一补词出现多次时加 `at`）。补出名词主语等需要交代的补词写在这里。
- `renderings`：`clauses[].contentTokens` 中的**每个实词**都要有一条；`zh` 必须是**去掉 `[ ]` 后的** `text` 里实际出现的字串。
  - 几个词整体译为一个中文词或短语时，`tokens` 写区间 `首-末`。第 4、5 档重组句子时常这样用。
  - 一个词的译法在译文里被别的词隔开时，`zh` 用「…」连接各段，各段按顺序出现：παθεῖν 在「受多少苦」里写 `受…苦`，中间的「多少」归 ὅσα。不要把别的词并进来写成 `受多少苦`。
  - `zh` 出现不止一处时，可以加 `at`（`zh` 在去掉 `[ ]` 后的译文中的起始位置，从 0 数）指明是哪一处；不给时系统按词序自动定位。briefing 里已有译文的 renderings 带着 `at`，改了译文后不必手算，删掉或留着都行。
  - 实词有意不译时 `zh` 写 `∅`；第 1–3 档还要加 `note`。
  - 虚词可以不给 rendering。
- `alternatives`：可选，其他译法，每条 `{text, kind, basis, reading?}`（见下文“争议”与 literalness.md）。
- `note`：说明；有 alternatives 时写主译的取舍理由（必填）。
- `paraTitle`：段落小标题（纯文本），见下文“段落与小标题”。
- 用了扩展工具时加 `"sources": ["ai", "ext:commentary"]`。

## 段落与小标题

`paraTitle` 非空即表示本子句开始新段落。段首可以在一节中间（如徒 8:1a 结束上一段，8:1b 起新段）。

- **子句带 `paragraph`**（这卷书有分段数据时）：段首由系统按分段数据设定，不能增删。
  - `paragraph.heading` 是分段数据（新约原文版本、旧约英文译本）的英文小标题：把它译成中文写进 `paraTitle`。
  - `paragraph` 为 `{}`：这里分段但没有小标题，不给 `paraTitle`。
  - 其余子句不给 `paraTitle`。
- **briefing 里没有 `paragraph`**（这卷书没有分段数据）：在自然段开头（场景、人物、时间地点转换，话题转换）可以给 `paraTitle`，概括这一段；不必每段都给。
- 两种情况都要：
  - 标题简短（一般不超过 12 个字），不加句号；专名、术语用本段译文和术语表的译法（如 `Saul` 照译文作“扫罗”），不要另起译名。
  - 段首前一子句的译文要收住句子，以句号、问号、叹号等结尾；节中分段时尤其注意，不要用逗号接到下一段。
  - 段首不能并进前一子句（不能是 `span: 0`），合并不跨过段首。

## 争议

异文与解经争议默认不处理。briefing 的 `disputes.enabled` 为 `true` 时，读 [disputes.md](disputes.md)，处理 `status: ambiguous`、`readings`、`disputes.textual`、`ambiguityHints`，并主动标出其他争议；提交时也传 `disputes: true`。

## 用词统一

`terms` 列出范围内每个实词义项（`senseKey`）：

- `glossary`：术语表条目。`locked` 必须照用；`preferred` 是默认译法。
- `history`：本书卷已有的译法及次数、出处。
- `maculaZh`、`ubsZh`：参考简义，不是定译。

规则：

1. 有 `locked` → 必须用该译法，否则该节被拒（各档都一样）。
2. 有 `preferred` 或 `history` → 默认沿用；确需不同时，在该 rendering 的 `note` 写理由，否则该节被拒并在 `consistency` 中列出。第 4、5 档不拒，只在 `consistency` 里提示。
3. 都没有 → 这是首次出现，认真选词：有 `preference`（术语偏好）时默认用它，不用 `avoid` 里的译法；重要的词提交后用 `upsert_glossary` 固化。
4. 同一 senseKey 下的正当分化（比喻义与本义、语域差异），写 note 后系统会放行；若这种分化会反复出现，考虑在术语表里按 `senseKey` 分别建条目。

## span（子句合并）

基准是逐句翻译（`span: 1`）。第 1 档不合并（系统拒绝 span>1）；第 3 档起判据 B 不再限制；第 4、5 档按意思合并，诗歌平行句也可以合并，但要写 note。以下是第 2 档的规则。

**合并的前提（第 2 档起各档通用）：合并必须改变了什么。** 只有两种情况值得合并：

1. 中文要调换语序：把后置的状语从句挪到前面，把关系从句译成前置定语嵌进主句。
2. 断开处会切在一个成分中间：主语从句与谓语之间（「凡……的，｜在我这里就算是偷来的」）、动词与不定式补语之间、前一行单独读不通的（「任凭他们｜去事奉…」）、「到了……的时候」这类框式结构中间。

宾语从句（`ὅτι`、`πῶς`、`τί`、`כִּי`、`אֲשֶׁר` 等引出的“说/知道/看见”的内容）本身是单独切出的子句，断在动词与它之间不算切在成分中间：中文语序与原文相同时各自成句，动词一行写到动词（和间接宾语）为止，如徒 9:27 「向他们述说｜他怎样在路上看见了主，｜[主]又对他说了话，｜以及他怎样在大马士革…放胆传讲。」、「我们不知道｜他遭遇了什么」。中文必须调换语序时才按 `reorder` 合并。

除此以外，各行顺序与原文相同的，即使某一行单独看不是完整的句子（「过了四十年，」「只要你为我做这件事，」），也不合并，各自 `span: 1`，中文按原文顺序一行接一行读下去。常见的误合并：

- 原文本来就在主句前面的状语成分：前置的属格独立结构（徒 7:30 `πληρωθέντων ἐτῶν τεσσεράκοντα` 过了四十年，｜…显现）、前置的分词小句、前置的条件从句（创 30:31 `אִם־תַּעֲשֶׂה־לִּי הַדָּבָר הַזֶּה` 只要你为我做这件事，｜我就回转，｜牧放…），前置的时间从句。它们不是判据 A 说的「后置」，原样各自成句。
- 接在后面的目的、结果不定式，或连续几个动作，中文顺着往下说也通的（「于是我下来，｜要解救他们。」「我就回转，｜牧放你的羊群，｜看守它们。」）。
- note 写的理由是「按中文前置合并」，可各行顺序其实和原文一样——这说明不需要合并。

**判据 A（合并前置）：后置状语造成语序倒置。** 原文把条件、时间、情状成分放在主句之后，中文按习惯要前置——拆开就会留下悬空的尾句。范围由 briefing 里 `approach.clauseOrder` 决定（来自 style.md 的 `clauseOrder`；第 1 档固定为 `source`，第 4、5 档固定为 `fluent`）：

- `fluent`（默认）：中文前置才通顺的，一律合并前置。
- `source`：时间从句、“直到”从句、不定式时间从句保留原文语序，各自成句；中文后置也能读通时不合并。

两种选项下，**后置的**条件从句（`אִם`、`ἐάν` 等）以及拆开会留下悬空尾句的情况都要合并前置；条件从句在原文里本来就在前的，不合并。典型形态：

- `אִם`、`כַּאֲשֶׁר`、`בְּטֶרֶם` 引导的后置从句
- `בְּ` / `כְּ` + 不定式的时间从句后置
- `waw` + 独立人称代词 + 分词的情状小句
- 新约中后置的 `ἐάν`、`ὅταν`、`ὡς` 时间/条件从句，同理判断

**判据 B（默认不合并）：中文也可后置的从句。** 原因（`כִּי`、`ὅτι` 表原因、`γάρ`）、关系（`אֲשֶׁר`、关系代词）、目的（`לְמַעַן`、`ἵνα`）从句各自 `span: 1`。引语框架（“神说：”）与引语内容也各自成句。

- 例外：`clauseOrder` 为 `fluent` 时，**简短的限制性关系从句**（去掉后先行词所指不明，如创 2:2 `מְלַאכְתּוֹ אֲשֶׁר עָשָׂה` 他所做的工）默认与先行词所在子句合并，译成前置定语（不后置成“就是……的”）。非限制性的、较长的关系从句仍各自成句；`source` 时一律不合并。例外之外还有一种情况两种选项下都要合并：修饰后置主语、单独成句会悬在谓语之后的关系从句（见下文“关系从句”），不论长短都合并前置。

**判据 C（不得合并）：同型平行对句。** 诗歌体的平行句一律各自成句，即使合并更顺口。

合并写法：

- 合并 N 个连续子句时，首句 `span: N`，其后 N-1 句 `span: 0`、`text: ""`、不给 renderings（renderings 都写在首句上）。
- 首句写 `merge` 说明理由：`reorder`（中文调换了语序）或 `constituent`（断开会切在一个成分中间，note 写明切在哪两个成分之间）；第 4、5 档另可写 `meaning`（按意思合并）。系统会核对 `reorder`：各行与子句一一对应、顺序和原文相同的，会被打回。
- 合并后的 `text` 用 `\n` 分行，行数与覆盖的子句数一致，**行序按中文语序**。
- 嵌入子句（briefing 里外层子句的原文在嵌入处写作 `⟨子句id⟩`）译成前置定语、嵌进外层那一行时，与外层合并（`merge: constituent`，note 写明嵌在哪两个成分之间），不单占一行；行数相应少一行。
- 合并不跨节。

## 语态

第 1–3 档语态照原文：

- 被动词干与被动分词（Niphal 的被动义、Pual、Hophal、`ἐ-…-θη` 被动）译出被动或状态，不改成主动，也不补“有人”“人”作施事：创 22:20 `וַיֻּגַּד לְאַבְרָהָם` 译“亚伯拉罕被告知”，不写“[有人]告诉亚伯拉罕”；25:8 `וַיֵּאָסֶף אֶל־עַמָּיו` 译“被收聚到他的族人那里”；25:10 `שָׁמָּה קֻבַּר אַבְרָהָם` 译“亚伯拉罕被埋葬在那里”；22:14 `אֲשֶׁר יֵאָמֵר הַיּוֹם` 译“所以今日有话说”，不写“今日人说”。
- Niphal 表反身、相互或只有主动义的动词（`נִשְׁבַּע` 起誓、`נִלְחַם` 争战、`נִשְׁאַר` 剩下）按词义译，不硬加“被”。
- Hiphil 的使动义译出来（“使……”“让……”），Qal 不加使动（24:27 `לֹא־עָזַב חַסְדּוֹ` 译“没有撇下他的慈爱”，不写“没有使他的慈爱离开”）。
- 由形态推出的“被、使”不加 `[ ]`。

## 连词

连词（וְ、καί、δέ、γάρ、οὖν 等）不要死板对译：

- 按它在上下文中的逻辑功能翻译（顺接、转折、因果、结果、解释），或者不译。
- 叙事中串联动作的 וְ / וַ、καί，中文通常不必译出；需要时用“就”“便”“于是”等自然衔接。
- 表示对比、转折、原因、推论时，要把这层逻辑关系译出来（如“却”“因为”“所以”）。
- 连词不要求 rendering，也不纳入用词统一检查。

小品词 `נָא` 不是表客气的“请”：它强化说话人的主观意愿、带出紧迫感，或承接上文引出相应的请求、命令（“那么就……”）。按语境选其中一种译出，如“务必”“就……吧”“这就”“那么”；语气轻、中文难以译出时可以不译，在 note 说明。`הִנֵּה־נָא` 同样处理，不译“请看”。

## 关系从句

拆句、前置、用代词或重述先行词承接等常规手法照常用；以下是容易出错、或与档位相关的几点：

- **希伯来文复指成分**：`אֲשֶׁר` 从句里回指先行词的代词后缀或副词（`בּוֹ`、`עָלֶיהָ`、`שָׁם` 等）。从句译成前置“所……的”定语时不再译出复指成分（“我所住的地”，不是“我所住在其中的地”），该词 rendering 写 `∅`，第 1–3 档 note 写“复指成分，前置定语中不译”；第 1 档可以保留字面。从句后置、单独成句时，复指成分正好译成承接的代词（“我曾住在那里”）。
- **“就是”只对应关系词**：后置的关系从句有 `אֲשֶׁר`、关系代词时，可以用“就是……的”接在先行词后面（创 30:26 `אֶת־נָשַׁי וְאֶת־יְלָדַי אֲשֶׁר עָבַדְתִּי אֹתְךָ בָּהֵן` 译“我的妻子们和孩子们，就是我为她们服事你的”），也可以合并前置或用代词承接。原文没有关系词的——同位语、时间状语从句（`כִּי` + 时间）、无标记关系从句——不补“就是”：同位语按下文“标点”一节处理（能不用破折号就不用），时间从句照常译“当……的时候”放在句首或单独成句（30:33 不写“……作证，就是当你来……的时候”）。
- **“就是……的”要紧贴先行词**：后置的“就是……的”只能接在先行词之后、且先行词是上一行的最后一个成分；先行词后面还跟着动词、宾语或别的短语（21:22 `אֱלֹהִים עִמְּךָ בְּכֹל אֲשֶׁר־אַתָּה עֹשֶׂה` 不写“神在一切[事]上与你同在，就是你所做的”），或先行词只是属格里的一项（25:12 `תֹּלְדֹת יִשְׁמָעֵאל … אֲשֶׁר יָלְדָה הָגָר`，“以实玛利的后代，就是夏甲……生的”会读成生了“后代”），就合并前置（“神在你所做的一切[事]上与你同在”），或重述先行词另起一句（“……以实玛利的后代；[以实玛利]是……夏甲给亚伯拉罕生的”）。`clauseOrder` 为 `fluent` 时，简短的限制性关系从句前置作定语是默认做法，不要后置成“就是……的”（21:23 不写“待我和那地，就是你所寄居的”，写“待我和你所寄居的地”）。
- **承接的指代要唯一**：后置从句用“他、它、这”承接时，先行词必须是前面最近的同类名词；中间隔着别的名词就重述先行词。第 1–3 档重述的先行词是补词，放进 `[ ]`。
- **隐含的逻辑关系**：关系从句有时带原因、让步、条件、目的意味（如带将来时直陈或 `ἄν` + 虚拟语气的关系从句）。第 1–3 档保留关系从句的形式，这层意思写进 note。第 4、5 档可以直接用“因为”“虽然”“为要”等连词译出。`ὅστις` 在通用希腊文里常与 `ὅς` 无别，不要一见就译成“既然”“因为”。
- **希伯来文无标记关系从句**：诗歌与部分散文省略 `אֲשֶׁר`，小句直接贴在（多为无冠词的）名词后面，如伯 3:3 `יוֹם אִוָּלֶד בּוֹ`（我出生的那日；`בּוֹ` 是复指成分）。不要译成并列句。
- **并列先行词**：几个并列名词共用一个关系从句时（徒 9:36 `ἔργων ἀγαθῶν καὶ ἐλεημοσυνῶν ὧν ἐποίει`，`ὧν` 指两者），前置定语放在整个并列结构前面（“她所行的善事和施舍”），不要只贴在最后一项上（“善行和她所行的施舍”）；后置成句时用“这些”等承接全部先行词。只修饰最后一项时照原文。
- **修饰后置主语的关系从句**：原文谓语在前、主语在后，关系从句又紧跟主语（徒 10:45 `ἐξέστησαν οἱ ἐκ περιτομῆς πιστοὶ ὅσοι συνῆλθαν τῷ Πέτρῳ`）时，子句行序虽与原文相同，中文主语却要提到谓语前，从句单独成句就会隔着谓语悬在句尾。这算调换语序：与主语所在子句合并（`merge: reorder`），译成前置定语；`ὅσοι`、`πάντες οἵ` 可用“凡……都”（“凡与彼得同来、受割礼的信徒都惊奇”）。不要在谓语后用“就是……的人”追补。
- **前置还是后置**：第 2 档能否合并前置见上文“span”的判据 B。
- **前置定语的长度**：中文名词前的“的”字结构超过两层，或前置后头重脚轻，就改为后置成句，或用“那……的，他……”的外位结构。

## 标点

- 引号要成对：直接引语用 “”，引语中再引用用 ‘’。
- 同一段引语跨节时，只在开始的那节加 “，在结束的那节加 ”；中间各节开头不再加 “。开引号加在引语第一句的开头，不加在前一句（“彼得回答：”）的末尾，即使两句在不同节（徒 10:46–47）。
- 子句的谓语后面紧接着它的宾语从句、补语从句（`ὅτι`、`πῶς` 等引出的听见、看见、知道的内容，间接引语），这一句末尾**不加标点**，与下一句直接连读；直接引语才用冒号。例：徒 11:1 “使徒们和在犹太各地的弟兄们听说”后面直接接“外邦人也接受了神的道。”，“听说”后不加逗号（8:14a“在耶路撒冷的使徒们听说”、8:18a“西门看见”同）。
- 主语再长（不定式、动词短语作主语）也不用逗号与谓语隔开。例：徒 10:28 “你们知道犹太人和外族人结交或来往是不合规矩的。”，“知道”后、“来往”后都不加逗号。
- 修饰成分——主语里的数量、形容词、定语分词，动词的方式、工具等状语（方式与格）——不拆出来另作谓语，也不用逗号与所修饰的部分隔开，原文的谓语仍是全句唯一的谓语。例：徒 11:21b πολύς τε ἀριθμὸς ὁ πιστεύσας ἐπέστρεψεν ἐπὶ τὸν κύριον 译“有许多信了的人归向了主。”，不译“信了的人为数众多，归向了主。”——后者把“为数众多”变成谓语，加逗号后读成两件事。又：徒 11:23d παρεκάλει πάντας τῇ προθέσει τῆς καρδίας προσμένειν τῷ κυρίῳ 译“劝勉众人要立定心志始终忠于主”，“立定心志”是“始终忠于主”的方式，后面不加逗号，否则读成两项劝勉。
- 名词的同位语（无动词的名词短语，如 `ἀνδρὶ συνετῷ`）不是子句，不另起一句、不补“是”作谓语；同位语里的每个实词照样译出，中心名词（`ἀνήρ`、`ἄνθρωπος` 等）也不省。能整个译成前置定语的就前置；中心名词放不进定语、前置或顿号并列都会漏词或改变意思时，才用破折号把同位语夹在名词后，不加“就是”（创 9:4 `בְּנַפְשׁוֹ דָמוֹ` 译“带着它生命——它的血——的肉”，不译“——就是它的血——”）。例：徒 13:7a `ὃς ἦν σὺν τῷ ἀνθυπάτῳ Σεργίῳ Παύλῳ, ἀνδρὶ συνετῷ` 译“他常和省长士求·保罗——一个聪明人——在一起”，不译“他常和聪明的省长士求·保罗在一起”（漏了 `ἀνδρί`），也不译“他常在省长士求·保罗那里，[士求·保罗]是个聪明人。”
- **能不用破折号就不用**：破折号打断句子，读来绕。同位语、插入成分先试着前置作定语、用顿号并列在名词前，或调整语序；一句里不要出现两组以上的破折号。例：创 11:31a `אֶת־לוֹט בֶּן־הָרָן בֶּן־בְּנוֹ וְאֵת שָׂרַי כַּלָּתוֹ אֵשֶׁת אַבְרָם בְּנוֹ` 译“他孙子、哈兰的儿子罗得，和他儿媳、他儿子亚伯兰的妻子撒莱”，不译“哈兰的儿子——他儿子的儿子——罗得，以及他儿媳撒莱——他儿子亚伯兰的妻子”。

## 常见错误

- **动作照原文**：动词译它本身的动作，不换成引申或解释出来的另一个动作。徒 9:15 `βαστάσαι τὸ ὄνομά μου` 译“承载我的名”，不译“宣扬 / 传扬”；9:22 `συνέχυννεν` 译“使……困惑”，不译“驳倒”；9:41 `παρέστησεν αὐτὴν ζῶσαν` 译“使她活着站在他们面前”，不译“把活着的她交给他们”。
- **词义照字面，语境义写进 note**：第 1–3 档名词、形容词、分词也一样，译它本身的词义，不换成按语境解释出来的说法；语境义、言外之意写进该词 rendering 的 `note`。创 29:31 `שְׂנוּאָה` 译“被恨”，不译“失宠”，note 写“与 30 节‘爱拉结胜过利亚’相对，指不如拉结受爱，不一定是憎恨”；27:42 `מִתְנַחֵם לְךָ` 译“因你安慰自己”，不译“向你报仇雪恨”，note 写“指以杀你来泄愤”。字面读来费解到不通时，才按 literalness.md 的“比喻、成语”一行处理。
- **语气跟着母句**：修饰命令句的分词带命令语气（徒 10:20 `πορεύου σὺν αὐτοῖς μηδὲν διακρινόμενος` 译“……不要疑惑”，不译“一点也不疑惑”）。
- **不添原文没有的词**：第 1–3 档不加原文没有的修饰语、解释语（9:1 `ἀπειλῆς καὶ φόνου` 译“恐吓和杀戮”，不加“之气”），不补原文没写的名词主语、宾语；指代不清非补不可时放进 `[ ]`（“于是[同行的人]牵着他的手”，不能直接写“于是同行的人”）。
- **名字的谐音写进 note**：起名、改名、地名由来的经文，名字常与下文解释里的某个词谐音。译文照常译，不为凑谐音改字；在专名的 rendering `note` 写明与哪个词谐音、名字是什么意思，被谐音的那个词的 `note` 也注明“与‘X’谐音”：创 41:51a“玛拿西”note 写“名字与 51b נַשַּׁנִי（使我忘却）谐音，意为‘使忘却’”，51b“使…忘却”note 写“与‘玛拿西’谐音”；41:52 以法莲与 הִפְרַנִי（使我繁盛）同样处理。
- **按现代汉语的意思检查旧说法**：和合本等旧译沿用下来的说法，现代汉语里意思变了的不用：创 41:16 `בִּלְעָדָי` 不译“这不在乎我”（现在读成“我不在意”），译“这不在于我 / 不是我”。
- **程度、范围、语气不加码**：译文的程度（最、非常、大大）、范围（万、凡、全）、确定语气（确实、明明、真）、数量（一个、一份）都要和原文相当，原文没有表达的就不加；一个词的 `zh` 也只写这个词本身的意思，不顺手带出原文没有的动作或色彩。为了中文通顺不得不加的，第 1–3 档放进 `[ ]`。
- **代词后缀照译**：第 1–3 档名词、介词、动词上的代词后缀（希伯来文 `־וֹ`、`־הּ`、`־י`、`־ךָ`，希腊文 `αὐτοῦ`、`μου` 等）译出相应的“他 / 她 / 我 / 你（们）”，人称、性、数对上，不漏译，也不改成“自己”：创 24:36 `אַחֲרֵי זִקְנָתָהּ` 译“在她年老之后”，不写“在年老之后”；24:67 `אַחֲרֵי אִמּוֹ` 译“在他母亲[去世]之后”；24:39 `אֶל־אֲדֹנִי` 译“对我主人”；25:5 `אֶת־כָּל־אֲשֶׁר־לוֹ` 译“属于他的一切”，不写“自己所有的一切”。原文本身是反身义（`לוֹ` 指主语本身作受益者，如 22:8 `יִרְאֶה־לּוֹ`“为自己预备”）时才用“自己”。固定搭配可不译：`נָשָׂא עֵינָיו` 举目、`שְׁמוֹ` 名叫、`לְבַדּוֹ` 单独。
- **中文句子要完整、通顺**：
  - 问句的“吗”只放在整句末尾，句中不先用“吗”断开再续（9:21“这人不就是……的，而且……吗？”，不写“……的吗，而且……吗？”）。
  - 成对的关联词要配齐：用了“一面”就要有第二个“一面”，用了“虽然”后面接“却 / 但”。
  - **主语换了人就译出代词**：中文的零主语会被读成接着上一句的主语（或上一句最显眼的人）。原文主语只在动词人称里、与上一句中文的主语不是同一个人时，按动词的人称和数译出代词（他 / 她 / 他们），不留零主语；代词来自动词词尾，不算补词，不加 `[ ]`（名词主语仍按“不添原文没有的词”）。逐句检查时以上一句**中文译文**的主语为准，不以原文为准。例：徒 13:5c–6 上一句是“那时也有约翰作他们的助手。”，6a `Διελθόντες … εὗρον` 是复数，若写“走遍了全岛，直到帕弗，遇见一个犹太人”就读成约翰在走、在遇见，要写“他们走遍了全岛……”。
  - **同性别的两个人轮流做主语，代词不能消歧**：上一句主语是“他”、这一句换了另一个“他”时，译出“他”仍会被读成上一句的人，要重述名字（第 1–3 档放进 `[ ]`）。叙事里两个男人（或两个女人）对话、交接东西时最常见：创 27:22 上一句“雅各就靠近他父亲以撒”，22b `וַיְמֻשֵּׁהוּ` 写“[以撒]就摸他”，不写“他就摸他”；29:23 上一句主语是拉班，23d 写“[雅各]就与她同房”；27:25e–h 递、吃、拿、喝轮流换人，每次换人都重述。
  - **不把主语改成“有……”句**：原文主语是人、动词是“有”（`ἔχω`）时，照原文以那人作主语（13:5c `εἶχον δὲ καὶ Ἰωάννην ὑπηρέτην` 译“他们也有约翰作助手”），不译“也有约翰作他们的助手”——后者把宾语约翰变成话题，下文的零主语就会被读成约翰。
  - 一句之内主语相同时不重复代词（“他正在去的路上，靠近了大马士革”，不写“他前去的时候，他正靠近大马士革”）。
  - 先出主语，再接它的动作，不把动作放在主语前面（徒 10:25“彼得进去的时候，哥尼流迎上去，俯伏在他脚前下拜”，不写“……的时候，迎上他，哥尼流俯伏……”）。
  - **一句里两个“他”指不同的人**：主语、宾语、领属语里同时出现指不同人的“他 / 她”（“他对他说”“带他到他家里”“[拉班]把他女儿给他”），重述其中一个的名字（第 1–3 档放进 `[ ]`），通常重述读者最难判断的那个：徒 10:27“他一面和[哥尼流]交谈”，不写“他与他交谈”；创 27:1h 以扫回答以撒，写“[以扫]对他说”；29:13g 写“带他到[拉班]家里”；30:15a 写“[利亚]对她说”。只有一个“他”、指代明确时不重述。
  - **提交前通读查指代**：整节译完后，对每个“他 / 她 / 他们”问一次“读者会以为是谁”。按中文译文读，以最近的、同性别的人为准；与原文所指不符就按上两条重述。
  - **“这是”不写成“这就是”**：`זֹאת`、`זֶה`、`הוּא`、`הִיא`、`οὗτος` 作主语的名词句译“这是 / 那是”，不加“就”（创 6:15“这是你造它的方式”、10:12“那是那座大城”）；原文另有强调词时才考虑“正是”。
  - 宾语、补语跟着动词，不拆到句末：“向他求给大马士革各会堂的文书”，不写“向他求文书给大马士革各会堂”。

briefing 有 `style` 时，按 principles.md 的“个人风格与术语偏好”处理：原文两种译法都成立时采用其中的偏好。

## 叙事文

以下是第 1–3 档的要求；第 4、5 档按 literalness.md 处理重复和强调，但原文明示的主语仍要译出。

- 保留重复结构，不为中文文风删减重复。
- 非主语前置成分有强调或焦点功能，译文要体现。
- 原文明示的主语（尤其重复出现的专名主语）必须译出，不得省为零主语。
