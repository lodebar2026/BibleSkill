## ClauseType 指南（新约希腊语）

本页只适用**新约**。旧约希伯来语见 [clause-type-guidance-hebrew.md](clause-type-guidance-hebrew.md)。

与旧约一样分两层名称：

- 展示句型：系统落盘与下游展示使用的短码，如 `AorX`、`Aor0`、`XAor`
- 基础句型：analyze 提交使用的全称，如 `aorist_ind`、`subjunctive`、`participle`

analyze 时提交基础句型全称，系统按 `subjectRange`、`verbRange` 自动换算成展示句型。

### 命名规则

- 后缀 `X`：有明示主语（`subjectRange` 有值）
- 后缀 `0`：无明示主语，主语只由动词人称词尾表示
- 前缀 `X`：有明示主语**且**主语位于动词之前

希腊语动词的人称词尾已经标明主语，所以**写出独立主语属于有标记的用法**，常带强调或对比意味，这与旧约的判断一致。译成中文时，`…0` 类不必补出主语代词；`X…`（主语前置）则往往需要用语序或「就是他」「正是这位」之类的措辞把重心译出来。

### 时体与叙事功能

希腊语靠「时体」承担旧约 wayyiqtol / qatal / yiqtol 所承担的篇章功能，对照如下：

| 希腊语 | 篇章功能 | 旧约的功能位 |
|---|---|---|
| 不定过去（aorist） | 叙事主线，推进事件 | 近于 wayyiqtol |
| 未完成（imperfect） | 背景、持续、反复、起始 | 近于背景性 qatal / 分词句 |
| 完成（perfect） | 过去动作留下的**现存状态** | 近于表既成状态的 qatal |
| 现在（present） | 当下、普遍真理；叙事中的历史现在时 | — |

---

### `AorX` / `Aor0` / `XAor`

基础句型：`aorist_ind`

不定过去时陈述语气。叙事文体的主线句型，把事件当作一个整体来陈述，不着眼于过程。

中文一般译为完成体（「就…了」「便…」），不必每句都加「曾经」。`XAor`（主语前置）多出现在场景转换或对比处，译时可用「至于…」「那时…就」等标出焦点。

### `IpfX` / `Ipf0` / `XIpf`

基础句型：`imperfect_ind`

未完成时陈述语气。表持续、反复、习惯，或动作的起始与未完成。

这是最容易在中文里丢掉的一类。译时常需补出体貌词：「一直…」「不住地…」「屡次…」「渐渐…」「就要…」。若原文用未完成时而译文只作简单过去，就抹掉了作者的着眼点，属于应当在偏离度检查中标记的语法损失。

### `PrsX` / `Prs0` / `XPrs`

基础句型：`present_ind`

现在时陈述语气。表当下发生、普遍真理，或书信中的现况。

**历史现在时**（叙事中用现在时讲过去的事，如福音书里的 λέγει「他说」）是希腊语特有的生动手法。中文没有对应形式，一般仍译为过去，但若该处明显在制造现场感（尤其是引入直接引语时），可在译文节奏上体现，不宜一律抹平。

### `PrfX` / `Prf0` / `XPrf`

基础句型：`perfect_ind`

完成时陈述语气。重点不在过去的动作，而在**该动作留下的、说话当下仍然存续的状态**。

中文常需用「已经…了」「（至今）仍…」把状态义译出来，如 γέγραπται「经上记着（现在仍这样记着）」、κέκριται「已经受了审判（现处于被定罪的状态）」。只译成一般过去会丢掉现存结果这一层。

### `PlpX` / `Plp0` / `XPlp`

基础句型：`pluperfect_ind`

过去完成时陈述语气，新约中较少见。表某过去时点之前已完成、并在那个时点仍存续的状态。中文可用「早已…」「此前已经…」。

### `FutX` / `Fut0` / `XFut`

基础句型：`future_ind`

将来时陈述语气。表将来事件，也可表命令（引旧约律法时常见）或表可能性。中文按语气分别译作「将要…」或「不可…／要…」。

### `SbjX` / `Sbj0` / `XSbj`

基础句型：`subjunctive`

虚拟语气。新约里最常见的几种用法：

- **ἵνα / ὅπως 引导的目的或结果从句**：译「为要…」「叫…」「以致…」
- **劝勉性虚拟**（第一人称复数）：译「我们…吧」
- **οὐ μή + 虚拟**：强调否定，语气远重于一般否定，译「断不…」「绝不…」
- **条件句的从句部分**（ἐάν + 虚拟）：译「若…」

虚拟语气本身不指时间，其体（不定过去 vs 现在）表达的是动作的观察方式，不是过去与现在之分。

### `OptX` / `Opt0`

基础句型：`optative`

祈愿语气，新约中罕见。最著名的是 μὴ γένοιτο「断乎不可」。表愿望或极委婉的可能性，中文用「愿…」「断乎不…」。

### `Ipv` / `IpvX`

基础句型：`imperative`

命令语气。主语通常隐含，故一般是 `Ipv`；出现呼格或显性主语时才是 `IpvX`。

**体的差异要留意**：不定过去命令式多指向一次性、具体的行动；现在命令式多指向持续、习惯性的行为，或（带否定时）停止正在进行的动作。中文可借「（就）去做…」与「要常常…」「不要再…」之类的措辞区分。

命令语气也用于请求与许可，需按语境判断语气强度，不必一律译成生硬的命令。

### `Inf`

基础句型：`infinitive`

不定式子句。希腊语不定式用法极广，主要有：

- **补语性**：跟在 δύναμαι、θέλω 等词后，译「能…」「愿意…」
- **目的**：译「为要…」
- **结果**：常带 ὥστε，译「以致…」
- **时间**：冠词化不定式带介词，`πρὸ τοῦ` +不定式=「在…以前」，`ἐν τῷ`+不定式=「正当…的时候」，`μετὰ τό`+不定式=「在…以后」
- **原因**：`διὰ τό` +不定式，译「因为…」
- **间接引语**：转述他人所说，译「说…」
- **作名词**：冠词 + 不定式整体当名词用

**冠词化不定式**（定冠词 + 不定式，常再带介词）是希腊语独有的结构，中文必须转成从句或介词短语，翻译时要明确判断它表的是时间、原因、目的还是结果。

### `Ptc`

基础句型：`participle`

分词子句。新约中数量极大，用法需分辨：

- **状语性分词**：表时间、原因、方式、条件、让步等。这是最常见的一类，中文一般转成从句：「…的时候」「因为…」「就…」
- **属格独立结构**（genitive absolute）：分词及其主语都用属格，且该主语与主句主语不同。中文须另起一个小句并把主语译出，否则读者会误以为与主句同一主语
- **定语性分词**：修饰名词，译「…的（人／事）」
- **名词性分词**：带冠词独立作名词，如 ὁ πιστεύων「那信的人」
- **迂说结构**（periphrastic）：εἰμί + 分词，整体相当于一个动词形式，不要拆成两句译
- **命令性分词**：少数分词带命令意味，译作祈使

分词本身不表时间，其体表示的是与主句动词的**相对关系**：不定过去分词多表主句动作之前或同时，现在分词多表同时进行。

### `Nom`

基础句型：`nominal`

无系词判断句。希腊语常省略 εἰμί，尤其在格言、定义、称号中。中文用「是」补出，或按判断句式译。

---

### 与旧约体系的区别（不要混用）

- 展示码互不重叠：看到 `AorX`、`Ptc`、`Nom` 就是新约；看到 `WayX`、`Ptcp`、`NmCl` 就是旧约。系统会按子句 id 的书卷号校验，用错约别的码会被拒绝。
- `imperative`、`participle`、`nominal` 三个**基础句型全称两约共有**，但展示码不同（旧约 `Impv`/`Ptcp`/`NmCl`，新约 `Ipv`/`Ptc`/`Nom`），由系统按书卷自动换算，不必自己判断。
- 希腊语没有 binyan（词干）层级，不要套用 Hiphil / Niphal 之类的判断；致使义与被动义分别由词汇本身、语态、或 δίδωμι／ποιέω + 不定式等结构承担。

### 取证

需要为某个用法找语法书依据时，若环境中有可检索语法书的扩展工具就用它查证，不要凭记忆写章节号；没有则在 note 中说明判断依据即可。
