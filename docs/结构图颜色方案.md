# 结构图颜色方案（新旧约统一）

2026-11-10 · 状态：已实现（第 8 节记录各步与修订）

结构图的每一种视觉手段（下称「通道」）只表示一个维度；新约、旧约用同一种通道表示可以类比的语法范畴。读者在两约之间切换时，不用重新学一遍颜色。

## 1. 设计原则

- **一通道一维度**：成分色条只管句法成分；字色按词类分工——名词性的词（含分词）标格，限定动词、不定式标时态或动词形式；外框只画在分词上，标它的时态；动词底色只管语气，角标只管语态或词干，荧光笔底色只管强调。
- **字色比外框直观**：一眼能看到的是字的颜色，细外框要找。最重要的动词时态（旧约的动词形式尤其关键）用字色；分词有名词性，格同样重要，字色留给格，时态退到外框。
- **两约对齐**：同一通道在两约表示可以类比的东西，比如叙事主线动词在两约同色。两约各自独有的范畴（新约的格、旧约的词干）放在同一通道的不同取值里，不另开通道。
- **动词信息集中在动词上**：时态、语气、语态（词干）都画在动词这个词本身，方框不再承担语法信息。
- **不只靠颜色**：每种颜色都配一个文字或形状提示（成分名、框头标签、角标字），色弱读者、黑白打印时也能读。
- **颜色一律用变量**：浅色、深色主题各定一版，页面里不写死颜色值。

## 2. 通道分工

各通道各管一件事，两约共用；只有「取值」因语言不同而异。

| 通道 | 表示什么 | 新约 | 旧约 |
| --- | --- | --- | --- |
| 成分块色条 | 句法成分 | 主语蓝、谓语红、其余灰 | 同左 |
| 字色（名词性的词、分词） | 格 | 主、宾、属、与、呼五格 | 不着色（没有格） |
| 字色（限定动词、不定式） | 时态 / 动词形式 | 不定过去、现在、未完成、将来、完成、过去完成 | wayyiqtol、qatal、yiqtol、weqatal、不定式 |
| 分词外框颜色 | 分词的时态 | 现在、不定过去、完成… | 一律棕框 |
| 动词底色 | 语气（有底色 = 动词） | 直说、祈使、虚拟、祈愿、不定式 | 直说、祈使、jussive、cohortative、不定式 |
| 右上角小字 | 语态 / 词干 | 中、被、中? | Ni、Pi、Hi、Ht（被动空心） |
| 荧光笔底色 | 强调 | 强调代词、标为前置的成分 | 前置成分、同根不定式 |
| 方框边框 | 不表示语法 | 中性色；顶层主句加粗 | 同左 |
| 连线 | 句法挂接 | 灰色，悬停橙色；逻辑关系青色虚线 | 同左 |

主线与离线仍由最外侧的主线竖线和框头「离线」标签表示，不占用颜色。

## 3. 句法成分色条（两约共用）

| 成分 | 色条 | 变量 |
| --- | --- | --- |
| 主语、同位语（配主语） | 蓝 | `--r-s` |
| 谓语 | 红 | `--r-v` |
| 宾语、间接宾语、状语、表语 | 灰 | `--muted` |
| 连词 | 浅灰虚线框 | `--r-conj` |
| 未标角色 | 更浅的灰 | `--r-none` |

成分名（「主语」「谓语」…）照旧写在色条下，不靠颜色也能读。

## 4. 格的字色

字色给名词性的词（名词、代词、形容词、冠词、分词）标格。限定动词、不定式的字色另表时态（第 5 节），它们都带语气底色，与同色的名词分得开。

| 格 | 浅色主题 | 深色主题 | 说明 |
| --- | --- | --- | --- |
| 主格 | 墨色（`--c-nom = --ink`） | 同左 | 不着色：最常见、常态不标（同不定过去、wayyiqtol）；主语另有蓝色条与「主语」字样 |
| 宾格 | `rgb(42,127,255)` 蓝 | `#6aa8ff` | 比现在式动词的纯蓝浅；动词另有语气底色，分得开 |
| 属格 | `rgb(0,160,0)` 绿 | `#4ade80` | |
| 与格 | `rgb(164,73,255)` 紫 | `#c084fc` | |
| 呼格 | `#db2777` 玫红 | `#f472b6` | 原为橙，与悬停高亮的橙色相撞，改玫红 |

- 不加粗：SBL 字体只有常规字重，主格不用加粗或描边。
- 曾改为主格蓝、宾格棕（665badb）；动词改用字色后，蓝色主格与现在式动词相撞，改回主格墨色、宾格蓝。
- 旧约名词不着色。原拟按标记类比格（`אֶת` 宾语用宾格色、`לְ` 用与格色、属格关系用属格色），放弃：旧约动词的字色已表示动词形式，名词再着色容易与蓝色的 weqatal 等混淆。
- 旧约动词的词干与格无关：词干用角标（第 5 节），不占字色。

## 5. 动词

动词的信息全画在动词这个词上：限定动词、不定式的字色 = 时态或形式，底色 = 语气；分词字色 = 格，外框 = 时态；右上角小字 = 语态或词干。

### 5.1 字色（分词为外框）：时态 / 动词形式

两约按「体」对齐；叙事主线动词在两约同为墨色——主线读来就是普通黑字，离开主线的形式（qatal、yiqtol、weqatal、分词）带色，自然跳出来。

| 词类 | 字色 | 外框 | 底色 |
| --- | --- | --- | --- |
| 限定动词、不定式 | 时态 / 形式 | — | 语气 |
| 新约分词 | 格 | 时态色 | — |
| 旧约分词 | 不着色 | 棕 | — |

| 颜色 | 新约 | 旧约 | 共同的意思 |
| --- | --- | --- | --- |
| 墨色（`--ink`） | 不定过去 | wayyiqtol | 叙事主线、完整事件 |
| 红 | 完成（`--t-perf`）；过去完成用深红（`--t-plpf`） | qatal | 结果、状态 |
| 绿 | 将来 | yiqtol | 未来、未然 |
| 蓝 | 现在 | weqatal | 未完成体、进行 |
| 紫红 | 未完成 | — | 过去的进行、背景 |
| 棕（`--t-ptcp`，外框） | — | 分词 | 状态、进行 |
| 灰 | 不定式（另有底色） | 不定式 | 非限定 |

旧约 wayyiqtol 由粉色改墨色，与新约不定过去同色；粉紫色只留给新约未完成式。旧约祈使、jussive、cohortative 是前缀形式一系，字色同 yiqtol（绿），靠底色区分（5.2）。

### 5.2 底色：语气

| 语气 | 新约 | 旧约 |
| --- | --- | --- |
| 直说 | 米色 `--m-ind` | 米色（原拟无底色；字色改表形式后，墨色的 wayyiqtol 要靠底色认出是动词） |
| 祈使 | 浅红 `--m-impv` | 浅红（祈使式） |
| 虚拟 | 浅紫 `--m-subj` | — |
| 意愿（祈愿、jussive、cohortative） | 浅绿 `--m-opt` | 浅绿 |
| 不定式 | 浅灰 `--m-inf` | 浅灰 |
| 分词 | 无底色 | 无底色 |

### 5.3 角标：语态 / 词干

| 新约（语态，按形式标） | 旧约（词干） |
| --- | --- |
| 主动不标 | qal 不标 |
| 「中」红：中间及中间异态（M、D） | Ni（niphal） |
| 「被」蓝：被动及被动异态（P、O） | Pi（piel），被动 Pu 空心 |
| 「中?」红：中被同形（N、E） | Hi（hiphil），被动 Ho 空心 |
| | Ht（hithpael） |

旧约词干由字色改成角标，词本身的字色空出来表示动词形式。

## 6. 强调：荧光笔底色

前置、同根不定式这类强调属于信息结构，与格、时态、语气无关，单独用一种底色：淡黄荧光笔色（`--hl`）。

| 层次 | 旧约 | 新约 |
| --- | --- | --- |
| 成分块底色 | 动词前的主语、宾语、状语（X-动词语序，如撒上 15:8 `וְאֶת־כָּל־הָעָם`） | 分析里明确标为前置强调的成分 |
| 词底色 | 同根不定式独立形强调动词（`מוֹת תָּמוּת`） | 显性的强调主语代词（`ἐγώ`、`σύ`） |

- 成分名后保留「· 前置」字样，框头保留「前置」标签，悬停说明前置的成分与作用（焦点、对比、转入背景）。
- 前置块不再用虚线边框；虚线框只留给同位语。
- 以后分析若区分话题前置与焦点前置：焦点用实色底，话题只描底边。现在先用一种。

## 7. 其余

| 元素 | 颜色 | 说明 |
| --- | --- | --- |
| 句法连线 | `--wire` 灰（浅 `#8a857c`、深 `#8f897f`） | 悬停时整条换 `--focus` 橙、加粗 |
| 逻辑关系 | `--logic` 青色虚线 | 只在逻辑与句法不同时画 |
| 异文角标「异」 | 改中性灰 | 现为强调色，过于抢眼 |
| 叙事主线竖线 | `--muted` 半透明 | |
| 原文字体 | 本机 SBL 字体 | SBL Greek / SBL Hebrew / SBL BibLit，没装时退到 Gentium Book Plus、Noto Serif Hebrew |

强调色只留两个：棕只用在节号、异文下划线、「句法：属…」说明与弹窗等辅助信息上，悬停用橙；框的结构一律用中性色——主句框与「主句」标签用墨色（浅色主题黑、深色主题近白），「从句」标签用灰，子句编号、占位符（墨字灰虚框）与「收起分支」按钮用墨色、灰色；句法连线用灰，不抢文字的颜色。所有颜色都定义成 `:root` 变量，深色主题在 `prefers-color-scheme: dark` 和 `[data-theme="dark"]` 下各定一版。
