# 结构图颜色方案（新旧约统一）

2026-11-10 · 状态：除第 8 节第 6 步（旧约按格类比着色，可选）外均已实现

结构图的每一种视觉手段（下称「通道」）只表示一个维度；新约、旧约用同一种通道表示可以类比的语法范畴。读者在两约之间切换时，不用重新学一遍颜色。

## 1. 设计原则

- **一通道一维度**：成分色条只管句法成分，字色只管名词的格，动词外框只管时态或动词形式，动词底色只管语气，角标只管语态或词干，荧光笔底色只管强调。
- **两约对齐**：同一通道在两约表示可以类比的东西，比如叙事主线动词在两约同色。两约各自独有的范畴（新约的格、旧约的词干）放在同一通道的不同取值里，不另开通道。
- **动词信息集中在动词上**：时态、语气、语态（词干）都画在动词这个词本身，方框不再承担语法信息。
- **不只靠颜色**：每种颜色都配一个文字或形状提示（成分名、框头标签、角标字），色弱读者、黑白打印时也能读。
- **颜色一律用变量**：浅色、深色主题各定一版，页面里不写死颜色值。

## 2. 通道分工

八个通道各管一件事，两约共用；只有「取值」因语言不同而异。

| 通道 | 表示什么 | 新约 | 旧约 |
| --- | --- | --- | --- |
| 成分块色条 | 句法成分 | 主语蓝、谓语红、其余灰 | 同左 |
| 字色 | 名词性的词的格 | 主、宾、属、与、呼五格 | 基本不着色；可选：有标记处按格类比（见第 4 节） |
| 动词外框颜色 | 时态 / 动词形式 | 不定过去、现在、未完成、将来、完成 | wayyiqtol、qatal、yiqtol、weqatal、分词、不定式 |
| 动词底色 | 语气 | 直说、祈使、虚拟、祈愿、不定式 | 祈使、jussive、cohortative；直说无底色 |
| 右上角小字 | 语态 / 词干 | 中、被、中? | Ni、Pi、Hi、Ht（被动空心） |
| 荧光笔底色 | 强调 | 强调代词、标为前置的成分 | 前置成分、同根不定式 |
| 方框边框 | 不表示语法 | 中性色；顶层主句加粗 | 同左 |
| 连线 | 句法挂接 | 灰色，悬停橙色；逻辑关系青色虚线 | 同左 |

主线与离线仍由最外侧的主线竖线和框头「离线」标签表示，不占用颜色。

## 3. 句法成分色条（两约共用）

| 成分 | 色条 | 变量 |
| --- | --- | --- |
| 主语、同位语（配主语） | 蓝 | `--r-s` |
| 谓语 | 红 | `--r-v` |
| 宾语、间接宾语、状语、表语 | 灰 | `--muted` |
| 连词 | 浅灰虚线框 | `--r-conj` |
| 未标角色 | 更浅的灰 | `--r-none` |

成分名（「主语」「谓语」…）照旧写在色条下，不靠颜色也能读。

## 4. 格的字色

字色只给名词性的词（名词、代词、形容词、冠词、分词）标格，动词的限定形式不着色。

| 格 | 浅色主题 | 深色主题 | 说明 |
| --- | --- | --- | --- |
| 主格 | `#1d4ed8` 蓝 | `#7aa2ff` | 与主语色条同色（`--c-nom = --r-s`），两约「蓝 = 主语」一致 |
| 宾格 | `#a16207` 棕 | `#d6a54a` 浅琥珀 | 原为蓝，让给主格 |
| 属格 | `rgb(0,160,0)` 绿 | `#4ade80` | |
| 与格 | `rgb(164,73,255)` 紫 | `#c084fc` | |
| 呼格 | 玫红（待定，如 `#db2777`） | 待定（如 `#f472b6`） | 原为橙，与悬停高亮的橙色相撞，改玫红 |

- 不加粗：SBL 字体只有常规字重，主格不再用加粗或描边，只用颜色。
- 旧约（可选）：没有格，但有标记的地方可以类比——`אֶת` 标出的宾语用宾格色，`לְ` 引出的间接宾语用与格色，属格关系（构造式后的 nomen rectus）用属格色。只在有明确标记处着色，其余照旧不着色。
- 旧约动词的词干颜色与新约格的颜色无关：动词和名词的格是两回事，词干改用角标（第 5 节），不再占字色。

## 5. 动词

动词的信息全画在动词这个词上：外框颜色 = 时态或形式，底色 = 语气，右上角小字 = 语态或词干。

### 5.1 外框颜色：时态 / 动词形式

两约按「体」对齐；叙事主线动词在两约同为墨色。

| 颜色 | 新约 | 旧约 | 共同的意思 |
| --- | --- | --- | --- |
| 墨色（`--ink`） | 不定过去 | wayyiqtol | 叙事主线、完整事件 |
| 红 | 完成、过去完成（加粗框） | qatal | 结果、状态 |
| 绿 | 将来 | yiqtol | 未来、未然 |
| 蓝 | 现在 | weqatal | 未完成体、进行 |
| 紫红 | 未完成 | — | 过去的进行、背景 |
| 棕（`--t-ptcp`） | — | 分词 | 状态、进行 |
| 灰 | 不定式（另有底色） | 不定式 | 非限定 |

唯一与现状冲突的调整：旧约 wayyiqtol 由粉色改墨色，与新约不定过去同色；粉紫色只留给新约未完成式。旧约祈使式改由底色表示（5.2），不再占外框颜色。

### 5.2 底色：语气

| 语气 | 新约 | 旧约 |
| --- | --- | --- |
| 直说 | 米色 `--m-ind` | 无底色 |
| 祈使 | 浅红 `--m-impv` | 浅红（祈使式） |
| 虚拟 | 浅紫 `--m-subj` | — |
| 意愿（祈愿、jussive、cohortative） | 浅绿 `--m-opt` | 浅绿 |
| 不定式 | 浅灰 `--m-inf` | 浅灰 |
| 分词 | 无底色 | 无底色 |

### 5.3 角标：语态 / 词干

| 新约（语态，按形式标） | 旧约（词干） |
| --- | --- |
| 主动不标 | qal 不标 |
| 「中」红：中间及中间异态（M、D） | Ni（niphal） |
| 「被」蓝：被动及被动异态（P、O） | Pi（piel），被动 Pu 空心 |
| 「中?」红：中被同形（N、E） | Hi（hiphil），被动 Ho 空心 |
| | Ht（hithpael） |

旧约词干由现在的字色改成角标，词本身的字色空出来给第 4 节的格类比用。

## 6. 强调：荧光笔底色

前置、同根不定式这类强调属于信息结构，与格、时态、语气无关，单独用一种底色：淡黄荧光笔色（`--hl`）。

| 层次 | 旧约 | 新约 |
| --- | --- | --- |
| 成分块底色 | 动词前的主语、宾语、状语（X-动词语序，如撒上 15:8 `וְאֶת־כָּל־הָעָם`） | 分析里明确标为前置强调的成分 |
| 词底色 | 同根不定式独立形强调动词（`מוֹת תָּמוּת`） | 显性的强调主语代词（`ἐγώ`、`σύ`） |

- 成分名后保留「· 前置」字样，框头保留「前置」标签，悬停说明前置的成分与作用（焦点、对比、转入背景）。
- 前置块不再用虚线边框；虚线框只留给同位语。
- 以后分析若区分话题前置与焦点前置：焦点用实色底，话题只描底边。现在先用一种。

## 7. 其余

| 元素 | 颜色 | 说明 |
| --- | --- | --- |
| 句法连线 | `--wire` 灰（浅 `#8a857c`、深 `#8f897f`） | 悬停时整条换 `--focus` 橙、加粗 |
| 逻辑关系 | `--logic` 青色虚线 | 只在逻辑与句法不同时画 |
| 异文角标「异」 | 改中性灰 | 现为强调色，过于抢眼 |
| 叙事主线竖线 | `--muted` 半透明 | |
| 原文字体 | 本机 SBL 字体 | SBL Greek / SBL Hebrew / SBL BibLit，没装时退到 Gentium Book Plus、Noto Serif Hebrew |

强调色只留两个：结构（编号、主句框）用棕，悬停用橙；句法连线用灰，不抢文字的颜色。所有颜色都定义成 `:root` 变量，深色主题在 `prefers-color-scheme: dark` 和 `[data-theme="dark"]` 下各定一版。
